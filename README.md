# Lupus: Reawakening

Beat 'em up 2D gótico-cyberpunk para Android. John "Lupus" Thorne luta em 3 formas (Humano, Lobo, Ascendido) ao lado de Vespera, Triton, Malakor, Echo e Brann contra a Cabala.

## Como baixar o jogo
Abra **Releases** e baixe o `LupusReawakening.apk` da versão mais nova ("Lupus Reawakening 9.x - APK N").
A 9.1 instala por cima da 9.0 e mantém o progresso.

## Como o APK é feito
As partes `LupusReawakening-zNN.zip` juntas formam o projeto Android. A cada envio, o GitHub Actions junta as partes, compila e publica o APK em Releases.

# CyberClaws

Beat 'em up 2D gótico-cyberpunk para Android. John Thorne luta em 3 formas (Humano, Lobo, Ascendido) ao lado de Vespera, Triton, Malakor, Echo e Brann contra a Cabala.
Até a versão 9.4 o jogo se chamava "Lupus: Reawakening".

## Como baixar o jogo
Abra **Releases** e baixe o `CyberClaws.apk` da versão mais nova ("CyberClaws 9.x - APK N").
A 9.7 instala por cima da 9.0 a 9.6 e mantém o progresso.

## Como o APK é feito
As partes `LupusReawakening-zNN.zip` juntas formam o projeto Android. A cada envio, o GitHub Actions junta as partes, compila e publica o APK em Releases.
